# PACKWORKS card-art generation brief

The production card art was generated with the built-in image-generation tool as twenty square contact sheets, then cropped into 240 local WebP files. The first five sheets use the original isometric-voxel direction; sets 6–20 use a more varied painterly tabletop-card direction while keeping the same crop-safe grid.

## Initial five-set shared prompt

Use case: stylized-concept

Asset type: production game art contact sheet for collectible card illustrations

Primary request: create exactly twelve clearly separated original isometric voxel diorama illustrations for the named fictional trading-card set, arranged as a strict 3-column by 4-row grid on one square sheet.

Style/medium: polished handcrafted isometric voxel game illustration, chunky geometric forms, crisp hard edges, rich material texture, expressive silhouettes, and premium collectible-card art quality; original designs only.

Composition/framing: exact 3x4 contact sheet, twelve equal landscape 4:3 cells, each cell filled edge to edge and centered around its named subject; thin perfectly straight dark gutters between cells; no outer frame; do not combine subjects across cells.

Constraints: exactly twelve panels; no text, letters, numbers, logos, trademarks, watermarks, card borders, UI, hands, existing franchise characters, commercial trading-card imagery, or repeated central humanoid; keep every panel visually distinct and readable at thumbnail size.

Avoid: generic AI fantasy art, soft airbrush, glossy mobile-game UI, photorealism, excessive bloom, identical compositions, and repeated front-facing portraits.

## Expansion shared prompt

Create a single square contact sheet containing exactly 12 separate landscape fantasy trading-card illustrations arranged in a strict 3-column by 4-row grid. Every cell must be a clean 4:3 landscape illustration with straight, evenly aligned gutters. Include no borders, card frames, labels, numbers, typography, logos, or watermarks. These are final crop-ready card-art panels.

Visual direction: handcrafted premium tabletop-card illustration, crisp painterly shapes, expressive silhouettes, tactile ink-and-gouache texture, and a sophisticated set-specific palette; beautiful and dramatic but not childish. Use one recurring world per sheet so the set feels cohesive, while ensuring each panel has a unique camera angle, subject, silhouette, and lighting. Place the twelve supplied subjects in exact reading order, left-to-right then top-to-bottom. Make every panel immediately distinguishable at thumbnail size. Do not merge panels or allow objects to cross gutters.

## Crop workflow

Each source sheet is cropped at exact thirds and quarters, trimmed slightly inside its gutters, resized to 640×480, and encoded as WebP:

```bash
node scripts/crop-card-sheet.mjs path/to/contact-sheet.png set-id
```
